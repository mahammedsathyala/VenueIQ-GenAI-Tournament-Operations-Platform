## Architecture

```
VenueIQ Platform
├── index.html          — SPA structure, 6 sections, AR Modal
├── styles.css          — Dark glassmorphic design system (~750 lines)
└── app.js              — GenAI simulation engine (~900 lines)
```

## Core Modules

| Module | Description | GenAI Component |
|--------|-------------|-----------------|
| **Operations Dashboard** | Real-time KPI cards, crowd heatmap, alert stream, AI insights | Predictive analytics, anomaly detection |
| **Dynamic Crowd Management** | Live density map, 6-zone occupancy, AI flow simulation, routing | Crowd flow prediction, proactive rerouting |
| **Smart Indoor Navigation** | Canvas-based wayfinding, 6 destinations, 4 modes, AR preview | Route optimization, accessibility-aware pathfinding |
| **Decision Support Hub** | Incident board, AI recommendations, resource dispatch, timeline | LLM-based incident analysis, command AI |
| **Multi-Language AI Assistant** | 4-persona chatbot, 40+ language support, translation engine, voice | Conversational AI, NLP, real-time translation |
| **Staff & Volunteer Ops** | Deployment map, task queue, skill matching, analytics | AI-optimized staff allocation |
